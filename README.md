# Meshki

**Meshki** — аддон-счётчик для фарма **«Мешочков сокровищ»** в WoW Sirus 3.3.5a. Отслеживает активную фласку, считает интервалы между мешочками, строит прогноз мешков за текущую фласку и скорость фарма в час, подаёт звуковой и световой сигнал, когда мешочек готов. Фарм мешочков теперь можно вести «не отрываясь» от убийства мобов — аддон сам подскажет, когда пора.

## Возможности

- **Таймер** — обратный отсчёт с визуальной полосой, статус `READY` когда мешочек доступен
- **Статистика** — всего мешков, за текущую фласку, прогноз на фласку
- **Метрики фарма** — средний интервал (сек), мешков/час, время простоя
- **Алерт** — зелёное свечение + звуковой сигнал `LEVELUP` когда мешочек готов
- **Автодетект иконки** — подхватывает иконку мешочка из loot-сообщений
- **Настройки** — масштаб, прозрачность, ширина, длительность таймера, вкл/выкл через панель интерфейса
- Ничего лишнего — нулевая активность в фоне, когда окно скрыто

## Установка

1. Скачайте/склонируйте репозиторий
2. Папку `Meshki` скопируйте в `Interface\AddOns\`
3. Перезагрузите игру или зайдите на персонажа
4. Окно аддон открывается автоматически (если включено)

## Команды

| Команда | Описание |
|---|---|
| `/mesh` | вкл/выкл аддон |
| `/mesh 20` | установить длительность таймера в секундах |
| `/mesh reset` | сбросить позицию окна |
| `/mesh stats` | сбросить статистику |
| `/mesh config` | открыть настройки |
| `/mesh debug` | отладочная информация |

## Настройки (Интерфейс → Аддоны → Meshki)

- Масштаб, прозрачность, ширина окна
- Длительность таймера
- Чекбокс «Включить аддон»

## Требования

- WoW Sirus 3.3.5a
- Фласка «Эликсир...» (отслеживается по ауре) для метрик за фласку
